## Hook

### useActionState

useActionState 可以根据某个表单动作的结果更新 state 的 Hook。
const [state, formAction, isPending] = useActionState(fn, initialState, permaLink?)

- state：当前的状态值
- formAction：绑定给表单的 action
- isPending： 更新状态
- fn：当表单操作时的函数
- initialState：state 初始值
- permaLink：可选的，一个包含了在特定情况下表单提交后将跳转到的独立 URL 的字符串

```jsx
import { useActionState } from "react";
async function increment(prev, formData) {
  return prev + 1;
}

function StatefulForm({}) {
  const [state, formAction] = useActionState(increment, 0);
  return (
    <form>
      {state}
      <button formAction={formAction}>+1</button>
    </form>
  );
}
```

面试题：

1. useActionState 和 useState 在处理表单状态上有什么区别？

- useState 需要手动处理表单事件和状态更新
- useActionState 自动绑定到表单 action，更适合处理基于表单提交的状态更新
- useActionState 内置了 pending 状态管理

2. useActionState 的底层原理是如何实现的？

- 利用 React 的 useState 来保存当前的状态
- 通过设置 isPending 状态来跟踪异步状态，自动在操作开始时设为 true，操作结束设为 false
- 自动从表单元素中提取 FormData, 将 FormData 作为第二个参数转递给 action 函数

### useCallback

useCallback 是一个允许在多次渲染中缓存函数的 React Hook
const cachedFn = useCallback(fn, deps)

- fn: 需要缓存的函数
- deps: 缓存的依赖项

```jsx
import { useCallback } from "react";
export default function ProductPage({ productId, referrer, theme }) {
  const handleClick = useCallback(
    (orderDetails) => {
      post(`/api/products/${productId}/click`, {
        referrer,
        theme,
        orderDetails,
      });
    },
    [productId, referrer, theme]
  );
}
```

面试题：

1. useCallback 的作用是什么？

- 缓存函数：避免函数在每次渲染时重新创建
- 性能优化：防止子组件不必要的重新渲染
- 依赖控制：只有当依赖项变化时才更新函数引用

2. useCallback 和 useMemo 有什么区别？

- useCallback 缓存的时函数本身
- useMemo 缓存的是函数执行结果

3. useCallback 的底层原理是什么？

- 引用缓存：通过闭包保存函数引用
- 依赖比较：使用浅比较判断是否需要更新缓存
- Fiber 集成：与 React 的调度和渲染机制深度集成
- 性能权衡：在某些请开给你下可能增加内存开销而非减少

### useContext

useContext 可以读取和订阅组件中的 context.
const value = useContext(MyContext)

- 向组件树深层传递数据
- 通过 context 更新传递的数据
- 指定后备方案默认值
- 覆盖组件树一部分的 context
- 在传递对象和函数时优化重新渲染

```jsx
import { createContext, useContext } from "react";

const ThemeContext = createContext(null);
const [theme, setTheme] = useState("dark");
export default function MyApp() {
  return (
    <ThemeContext value={theme}>
      <Form />
    </ThemeContext>
  );
}

function Form() {
  return (
    <Panel title="Welcome">
      <Button>Sign up</Button>
      <Button>Log in</Button>
    </Panel>
  );
}

function Panel({ title, children }) {
  const theme = useContext(ThemeContext);
  const className = "panel-" + theme;
  return (
    <section className={className}>
      <h1>{title}</h1>
      {children}
    </section>
  );
}

function Button({ children }) {
  const theme = useContext(ThemeContext);
  const className = "button-" + theme;
  return <button className={className}>{children}</button>;
}
```

面试题：

1. useContext 相比 props drilling 有什么优势？

- 避免层层传递：无需通过中间组件手动传递 props
- 提高可维护性：减少组件间的耦合度
- 更好的可读性：组件不需要接收与自身无关的 props
