要防止浏览器缓存，需要在HTML头部添加禁用缓存的meta标签，并在Vite配置中设置构建时的缓存策略。

添加禁用缓存的meta标签到HTML头部：index.html

在Vite配置中添加构建时的缓存控制设置：vite.config.js


防缓存配置：

1. HTML头部添加了禁用缓存的meta标签：

```html
<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate" />
<meta http-equiv="Pragma" content="no-cache" />
<meta http-equiv="Expires" content="0" />
```

2. Vite构建配置添加了文件hash：
```javascript
  build: {
    minify: 'terser',
    chunkSizeWarningLimit: 2000,
    outDir: 'dist',
    rollupOptions: {
      output: {
        //文件hash
        entryFileNames: 'assets/[name].[hash].js',
        chunkFileNames: 'assets/[name].[hash].js',
        assetFileNames: 'assets/[name].[hash].[ext]'
      }
    }
  }
```

所有JS/CSS文件名都会包含hash值

文件内容变化时hash会自动更新

强制浏览器重新下载新版本文件

这样配置后，每次构建都会生成带有唯一hash的文件名，浏览器无法使用旧的缓存文件。
