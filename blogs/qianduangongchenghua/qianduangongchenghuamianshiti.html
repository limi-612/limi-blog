构建工具对比

1. Webpack vs Vite

Webpack特点:

  • 成熟稳定，生态丰富
  • 基于模块打包，适合复杂项目
  • 配置灵活但相对复杂
  • 冷启动较慢，热更新速度一般

Vite特点:

  • 开发时基于ESM，生产时使用Rollup
  • 冷启动极快，热更新迅速
  • 配置简单，开箱即用
  • 对现代浏览器友好

2. 核心配置对比

// Webpack配置
module.exports = {
    entry: './src/index.js',
    output: {
        path: path.resolve(__dirname, 'dist'),
        filename: '[name].[contenthash].js'
    },
    module: {
        rules: [
            {
                test: /\.js$/,
                use: 'babel-loader',
                exclude: /node_modules/
            }
        ]
    }
};

// Vite配置
export default {
    build: {
        rollupOptions: {
            output: {
                manualChunks: {
                    vendor: ['vue', 'vue-router']
                }
            }
        }
    }
};

module.exports = { readFile };

    return { init: function() {} };

3. 缓存策略

// Webpack缓存配置
module.exports = {
    output: {
        filename: '[name].[contenthash].js',
        chunkFilename: '[name].[contenthash].chunk.js'
    },
    optimization: {
        moduleIds: 'deterministic',
        runtimeChunk: 'single',
        splitChunks: {

                    name: 'vendors',

部署与CI/CD

1. Docker容器化

FROM node:16-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]

2. GitHub Actions

name: Deploy
on:
    push:
        branches: [main]
jobs:
    deploy:
        runs-on: ubuntu-latest
        steps:
            - uses: actions/checkout@v2
            - name: Setup Node.js
              uses: actions/setup-node@v2
              with:
                  node-version: '16'
            - name: Install dependencies
              run: npm ci
            - name: Run tests
              run: npm test
            - name: Build
              run: npm run build
            - name: Deploy
              run: npm run deploy

监控与调试

1. 性能监控

// 性能指标收集
const observer = new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
        console.log(`${entry.name}: ${entry.duration}ms`);
    }
});

observer.observe({ entryTypes: ['measure', 'navigation'] });

2. 错误监控

// 全局错误捕获
window.addEventListener('error', (event) => {

    // 发送到监控服务
});

window.addEventListener('unhandledrejection', (event) => {
    console.error('Unhandled promise rejection:', event.reason);
});
