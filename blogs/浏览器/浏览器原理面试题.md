## 浏览器渲染流程

### 1. 关键渲染路径
1. **HTML解析**: 构建DOM树
2. **CSS解析**: 构建CSSOM树  
3. **渲染树构建**: DOM + CSSOM = Render Tree
4. **布局计算**: 计算元素位置和大小
5. **绘制**: 将像素绘制到屏幕

### 2. 重排与重绘
```javascript
// 触发重排的操作
element.style.width = '100px';
element.offsetWidth; // 强制同步布局

// 优化：批量操作
element.style.cssText = 'width: 100px; height: 200px;';

// 使用transform避免重排
element.style.transform = 'translateX(100px)';
```

### 3. 复合层优化
```css
/* 创建复合层 */
.optimized {
    will-change: transform;
    transform: translateZ(0); /* 或 translate3d(0,0,0) */
}

/* GPU加速动画 */
@keyframes slide {
    from { transform: translateX(0); }
    to { transform: translateX(100px); }
}
```

## 事件循环机制

### 1. 宏任务与微任务
```javascript
console.log('1');

setTimeout(() => console.log('2'), 0);

Promise.resolve().then(() => console.log('3'));

console.log('4');

// 输出顺序: 1, 4, 3, 2
```

### 2. 任务队列优先级
```javascript
// 微任务队列
Promise.resolve().then(() => console.log('Promise'));
queueMicrotask(() => console.log('queueMicrotask'));

// 宏任务队列
setTimeout(() => console.log('setTimeout'), 0);
setImmediate(() => console.log('setImmediate')); // Node.js

// 执行顺序：同步代码 → 微任务 → 宏任务
```

## 内存管理

### 1. 垃圾回收机制
```javascript
// 标记清除算法
function createClosure() {
    let largeData = new Array(1000000);
    
    return function() {
        // largeData被闭包引用，不会被回收
        return largeData.length;
    };
}

// 避免内存泄漏
function optimized() {
    let largeData = new Array(1000000);
    let length = largeData.length;
    largeData = null; // 手动释放引用
    
    return function() {
        return length;
    };
}
```

### 2. 常见内存泄漏
```javascript
// 1. 全局变量
window.globalVar = new Array(1000000);

// 2. 定时器未清除
const timer = setInterval(() => {
    // 处理逻辑
}, 1000);
// clearInterval(timer); // 记得清除

// 3. DOM引用
let element = document.getElementById('button');
document.body.removeChild(element);
// element = null; // 清除引用

// 4. 闭包引用
function attachListener() {
    let largeData = new Array(1000000);
    
    document.getElementById('button').onclick = function() {
        // largeData被意外保持引用
    };
}
```

### 1. 同源策略
```javascript
// 同源：协议 + 域名 + 端口都相同
// https://example.com:443/page1
// https://example.com:443/page2 ✓ 同源

// 跨域解决方案
// 1. CORS
fetch('https://api.example.com/data', {
    credentials: 'include'
});

// 2. JSONP
function jsonpCallback(data) {
    console.log(data);
}

// 3. 代理服务器
// 开发环境配置代理
```

### 2. XSS防护
```javascript
// 输入验证
function sanitizeInput(input) {
    return input
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;')
        .replace(/"/g, '&quot;')
        .replace(/'/g, '&#x27;');
}

// CSP策略
Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'
```

### 3. CSRF防护
```javascript
// CSRF Token
<meta name="csrf-token" content="{{ csrf_token() }}">

// 请求头添加token
fetch('/api/data', {
    method: 'POST',
    headers: {
        'X-CSRF-TOKEN': document.querySelector('meta[name="csrf-token"]').content
    }
});
```

## 性能监控

### 1. Performance API
```javascript
// 页面加载性能
const navigation = performance.getEntriesByType('navigation')[0];
console.log('DNS查询:', navigation.domainLookupEnd - navigation.domainLookupStart);
console.log('TCP连接:', navigation.connectEnd - navigation.connectStart);
console.log('首字节时间:', navigation.responseStart - navigation.requestStart);

// 资源加载性能
const resources = performance.getEntriesByType('resource');
resources.forEach(resource => {
    console.log(`${resource.name}: ${resource.duration}ms`);
});
```
